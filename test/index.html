Start / end frame (optional)
Pin the video's first and/or last frame to an image. Each image is centre-cropped to the generation's aspect ratio and sized to it before sending, so nothing gets stretched.
Motion swap (Ref2VA session only, optional)
Reference video: 24fps, 15s or shorter (the worker refuses anything else). Duration is set to its length. In the prompt it's <Video 1> and its soundtrack <Audio 1>; the finished video keeps the original soundtrack. Pictures are <Picture 1>-<Picture 3>, one character each. Turbo: "Turbo (Ref2VA, 8-step 768p)" with Steps 8 (better, ~2x the time), or "Turbo (Ref2VA, 4-step)" with Steps 4 (fastest). Upscale: start with None - RTX 2x crashed a 15s swap on the pod.

S3 credentials (to fetch the finished video)

handler.py uploads the result to Wasabi (S3-compatible, third-party - decoupled from whichever RunPod datacenter the GPU worker lands in) and only returns its key, not a URL - these are needed to turn that key into an actual downloadable/playable link.

GPU Session (held-open worker)

Required. handler.py only accepts session-mode jobs now - there's no classic one-shot fallback, enforced server-side so it can't be bypassed by skipping this page. Click Run GPU below, wait for "Session ready", then Run Generation queues onto that held-open worker. Mirrors minimax-h3-worker's run_session pattern, using its own comfylab_gpu_sessions/comfylab_active_gpu_sessions/ comfylab_gpu_session_jobs tables (same Supabase project, but isolated from the production billing tables - safe to use the public anon key here).

Ref2VA: the first session downloads it (~21GB, once). No turbo LoRA and no start/end frames on it (the worker refuses both); use the Wan refine engine, not H3. A and B are the base model and DaSiWa Hybrid V3 in an order this browser drew with a cryptographic coin flip on first load and keeps until you re-draw. Job results here show "Model A"/"Model B", never the real name.
No session.

Upscale a video

Upload any video (16s or shorter) and upscale it with RTX Video Super Resolution. Runs as its own RunPod job - no GPU session needed, and H3 isn't loaded. Needs the endpoint ID, API key and S3 keys above. If a GPU session is running and the endpoint only allows one worker, this waits in RunPod's queue until the session ends. The original audio is kept. Output is capped at 4096px per side (13.1MP), so 4x fits videos up to 1024x800.

Refine faces (post-generation)

Re-draws small faces in a video you already generated: each person's face is tracked and cropped (ComfyUI-H3-FaceRefine's tracker), the crops are redrawn by Wan 2.2's low-noise model, and pasted back. Faces 120px tall and up are left untouched; full strength at 30px and below. Runs on the GPU session above. The first refine on a volume downloads the Wan models (~22.5GB, once). Upscaled sources are refined at native size and upscaled back.
